# Хроники Этерны — мод для AzerothCore 3.3.5a

Мод-контент по мотивам «Хроник Этерны» Веры Камши на готовой зоне
Драконьего Погоста (map 0, zone 139). Три самодельные фракции заменены
штатными фракциями WoW 3.3.5a, контент расширен до 4 цепочек и 16 квестов.

---

## Фракции (реальные, из `factiontemplate_dbc`)

| Роль | ID | Кто |
|---|---|---|
| Талиг | **35** | дружелюбная нейтральная: лагерь, советники, торговцы |
| Дриксен | **14** | враждебная (гуманоиды): патрули, Гуннар, разведчики |
| Гайифа | **16** | враждебная: маги, пожиратели томов, боссы |

**Почему 35, а не 72/29:** фракция 35 нейтральна и Альянсу, и Орде —
квесты берут обе стороны без дублей и без правки клиента.
72 (Stormwind) нужен только для репутации игрока, поэтому она выдаётся
через Lua-хук `ModifyReputation` по команде игрока.

| Что | Репутация |
|---|---|
| Цепочки 1, 3, 4 | 935 Argent Crusade (нейтральная, у обеих сторон) |
| Дополнительно в 1 и 2 | 72 Stormwind / 29 Orgrimmar |

## Установка

```cmd
cd C:\Users\Orel\Documents\MultiTool\HomeChats\Chat-17\mod-eterna
install_world.bat acore_world
```

Скрипт применяет файлы в этом порядке:

```
00_factions_real.sql      — фракции NPC (35/14/16)
01_creature_template.sql  — базовые NPC
02_item_template.sql      — предметы
03_quest_template.sql     — цепочка 1
04_spawns.sql             — спавны цепочки 1
05_factions.sql           — репутация
06_areatrigger.sql        — Врата Кэртианы
07_creature_text.sql      — реплики
08_creature_spells.sql    — способности
10_npc_expansion.sql      — NPC цепочек 2–4
11_quest_chains.sql       — цепочки 2–4
12_spawns_expansion.sql   — спавны цепочек 2–4
```

Lua: скопировать `lua_scripts\eterna\` в `<server>\lua_scripts\eterna\`,
в `worldserver.conf`:

```ini
Eluna.Enable     = 1
Eluna.ScriptPath = "lua_scripts"
```

## Ограничения

1. **Спавны не проверены визуально.** Координаты в зоне Драконьего Погоста
   подобраны по рельефу; после запуска пройдите `.gps` и поправьте
   `04_spawns.sql` / `12_spawns_expansion.sql`.
2. **Репутация Талига** идёт в 935 Argent Crusade и 72/29; текст NPC
   говорит «Талиг запомнит», но вкладки «Талиг» в клиенте нет.
   Если нужна своя фракция — см. `docs/CLIENT_PATCH.md`.
3. **Модель Некрофага** (910031) — овца-полиморф (displayid 856) как заглушка.
4. **Квестированный NPC** (910020, 910030) не дают квестов — только
   убиваются. Все квестодатели — нейтральные NPC, доступные обеим сторонам.
5. **Боссы** (910040, 910041, 910043) стоят в open-world зоне; при соло-игре
   рассчитаны на 55–62 уровень.
6. **Eluna**: хуки `RegisterPlayerEvent(19)` и `(33)` есть в mod-ale
   этой сборки; если событие не срабатывает — проверьте лог worldserver.
