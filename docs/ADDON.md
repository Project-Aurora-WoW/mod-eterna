# Аддон EternaChronicles

Клиентский аддон-путеводитель по моду «Хроники Этерны». Показывает
статус всех 16 квестов, расположение лагеря, список NPC и наград.

---

## Основа

Аддон написан с нуля под API 3.3.5a (Interface 30300), без внешних
библиотек. За основу структуры взята стандартная схема WoW-аддонов
(как у `QuestLogEx` / `MapCoords`): `TOC` + `Core` (события, команды) +
`Data` (константы мода) + `UI` (фрейм).

Почему не взяли готовый аддон:

| Аддон | Почему не подходит |
|---|---|
| QuestLogEx / QuestHelper | завязаны на стандартные квесты и Blizzard-фреймы, ломаются от кастомных ID |
| Carbonite | тяжёлый, требует свою базу и карты, не поддерживает кастомные фракции |
| TomTom | только точки на карте, без статуса цепочек |
| AtlasLoot | только предметы, без квестов |

Свой аддон весит ~14 КБ и ничего не ломает.

---

## Что умеет

| Вкладка | Содержимое |
|---|---|
| **Цепочки** | 4 цепочки, прогресс «выполнено N из M», статус каждого квеста |
| **Лагерь** | координаты лагеря Талига и 10 NPC с ID и позицией |
| **Предметы** | 24 предмета мода с редкостью и типом |
| **Статус** | репутация Талига, общий прогресс |

Статусы: `◆` сдан · `◇` в журнале · `·` доступен.

Команды:
- `/eterna` или `/этерна` — открыть/закрыть окно;
- `/eterna reset` — сбросить позицию окна.

---

## Установка

Аддон уже скопирован в клиент:

```
E:\World of Warcraft 3.3.5a (ruRu enGB enUs) (12340)\Interface\AddOns\EternaChronicles\
    EternaChronicles.toc
    Core.lua
    Data.lua
    UI.lua
```

На экране выбора персонажа нажмите **«Аддоны»** и отметьте галочку
у «Хроники Этерны».

**Важно:** клиент должен быть запущен как 3.3.5a (Interface 30300).
Утилита `WoWMultiserverLauncher.exe` определяет версию по `## Interface`
в TOC — он выставлен.

---

## Если клиент не видит аддон

В 3.3.5a все аддоны проверяются по TOC в корне клиента. Частые причины:

1. **Папка лежит не там.** Должен быть
   `<клиент>\Interface\AddOns\EternaChronicles\EternaChronicles.toc`,
   а не `...\AddOns\EternaChronicles\EternaChronicles\EternaChronicles.toc`.
2. **Кириллица в именах LUA.** Файлы сохранены в UTF-8 без BOM — это
   требование клиента.
3. **Строка `## Interface:`** должна быть `30300` (для 3.3.5a).
4. **Кэш.** Удалите `WTF\Account\<аккаунт>\SavedVariables\EternaChronicles.lua`,
   если аддон включался с ошибкой.

---

## Проверка

1. Введите `/eterna` в чате — должно открыться окно.
2. Вкладка «Цепочки» — все 4 цепочки на месте, статусы серые (`·`).
3. Вкладка «Лагерь» — координаты `X -3830.5 Y -1250.2`.
4. Возьмите квест у Фернандо — статус «Вестник с севера» станет `◇`.

## Ограничения

- **Репутация «Талиг» (5010)** появится во вкладке «Статус» только после
  клиентского патча `Faction.dbc` (`docs/FACTION_TALIG.md`). До этого
  аддон покажет пометку, что фракция не найдена.
- **Карта Кэртианы** аддон не рисует — координаты лагеря работают в
  существующей зоне Драконьего Погоста.
- **Синтаксис Lua не проверялся интерпретатором** — на машине нет Lua.
  Логика написана по API 3.3.5a, но первый запуск может выявить опечатки;
  в этом случае клиент покажет ошибку в `Interface\AddOns\EternaChronicles`.
