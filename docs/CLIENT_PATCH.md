# Клиентский патч: фракции и модели

Сервер уже знает три фракции (5001 Талиг, 5002 Дриксен, 5003 Гайифа) и выдаёт
по ним репутацию. Но клиент рисует цвет NPC и вкладку репутации по своему
`Faction.dbc`. Пока DBC не пропатчен, отношения могут отображаться неверно.

Инструменты на машине:

- WDBX.Editor: `C:\Users\Orel\Downloads\WDBX.Editor`
- MPQ Editor: `C:\Users\Orel\Desktop\Ladik's MPQ Editor\Russian\x64`
- Клиент: `E:\wow\World of Warcraft 3.3.5a` (ruRU / enGB / enUS)

---

## Шаг 1. Экспорт Faction.dbc

1. Запустите **WDBX.Editor**.
2. `File → Open` → `E:\wow\World of Warcraft 3.3.5a\Data\ruRU\locale-ruRU.MPQ`.
3. Выберите `DBFilesClient\Faction.dbc`.
4. `Export DBC…` → сохраните как `Faction.dbc` в рабочую папку
   (например, `C:\Users\Orel\Documents\MultiTool\HomeChats\Chat-17\mod-eterna\client\`).

> В 3.3.5a `Faction.dbc` живёт внутри `locale-*.MPQ` и внутри `common-2.MPQ`.
> Патч в `patch-4.MPQ` перекрывает оба, поэтому достаточно одного файла.

## Шаг 2. Добавление записей

`Faction.dbc` — обычная DBC-таблица. Нужно добавить три строки с ID
`5001`, `5002`, `5003`, скопировав структуру существующих фракций:

| Новая ID | Что скопировать | Имя (Name_lang) | Описание |
|---|---|---|---|
| 5001 | 1602 (The Silver Covenant) или 1104 (Silvermoon City) | Талиг | Дом Олларов. Древняя династия, чей герб — леопард. |
| 5002 | 116 (Scourge Invaders) — только структуру | Дриксен | Вольные роты севера. Не признают Этерну. |
| 5003 | 116 — только структуру | Гайифа | Архив магов. Помнят больше, чем позволяет время. |

Поля, которые важно выставить при копировании:

- `ID` — 5001/5002/5003;
- `ReputationListID` — 0 (иначе фракция попадёт в чужую группу репутации);
- `ParentFactionID` — 0;
- `Name_lang` (все локали) — Талиг / Дриксен / Гайифа;
- `Description_lang` — из таблицы выше.

Для Талига (5001) скопируйте дружелюбную фракцию целиком — тогда
`FactionTemplate`-биты останутся правильными для игрока.

> Если WDBX.Editor не даёт копировать строки, экспортируйте в CSV
> (`Export → CSV`), добавьте три строки в текстовом редакторе и импортируйте
> обратно (`Import → CSV`).

## Шаг 3. Сборка MPQ

1. Запустите **Ladik's MPQ Editor** (`...\Russian\x64\MPQEditor.exe`).
2. `Файл → Создать новый архив` → путь
   `E:\wow\World of Warcraft 3.3.5a\Data\ruRU\patch-4.MPQ`
   (формат MPQ v3, размер хэш-таблицы по умолчанию).
3. `Операции → Добавить папку` или перетащите файл.
4. **Важно:** файл должен лежать внутри архива по пути
   `DBFilesClient\Faction.dbc`, а не в корне.
5. Закройте архив с сохранением.

## Шаг 4. Проверка

1. Удалите кэш: `E:\wow\World of Warcraft 3.3.5a\Cache\WDB\ruRU\` (или всю папку `WDB`).
2. Запустите клиент.
3. `.go creature 910000` — Фернандо должен быть зелёным (дружелюбным).
4. `.go creature 910020` — Солдат Дриксена должен быть красным.
5. Откройте вкладку репутации: «Талиг» должна появиться в списке.

## Альтернатива без правки DBC

Если патч клиента не нужен, используйте **существующие фракции AC** вместо
5001–5003. Тогда достаточно заменить номер фракции в
`sql/world/01_creature_template.sql` (`faction` = 5001/5002/5003) и в
`05_factions.sql` на подходящие из стандартного набора, например:

- 35 — дружелюбная нейтральная;
- 16 — враждебная (монстры);
- 14 — враждебная (гуманоиды).

Репутация вкладкой при этом не появится, но NPC будут выглядеть корректно.

## Модели NPC

Модели из таблицы мода — стандартные WotLK (1568, 3523, 4294, 15372, 16067, 21088).
Они уже есть в клиенте, патч не нужен.

**Некрофаг (910031)** стоит с моделью 856 (овца-полиморф) как заметная заглушка.
Чтобы заменить:

1. Откройте `CreatureDisplayInfo.dbc` в WDBX.Editor.
2. Найдите подходящий `ID` (например, 235 — скелет-нежить).
3. Выполните на сервере:
   ```sql
   UPDATE creature_template_model SET CreatureDisplayID = 235
   WHERE CreatureID = 910031 AND Idx = 0;
   ```
4. Перезайдите в игру (модель кэшируется).
